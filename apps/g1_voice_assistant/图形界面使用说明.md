# G1 图形语音控制

文件目录：`E:\siji basic\unitree G1`。

## 运行条件

- 电脑通过网线连接机器人，机器人地址为 `192.168.123.164`。
- 机器人已经安装好 `/home/unitree/g1_voice/.venv` 及宇树 Python SDK。
- 电脑使用现有 Codex 随附 Python 和 Tk。启动入口使用当前用户目录下的随附运行环境；若日后运行环境被卸载或移动，需要修改启动文件内的路径。
- **Paramiko 4.0.0 及依赖已安装。** 安装位置为本目录的 `gui_deps`，程序优先从这里导入；已通过依赖加载和本地窗口启动验证。
- GUI 使用当前 Windows 用户的 `%USERPROFILE%\.ssh\known_hosts` 验证主机身份。如提示主机未记录，请先用 PowerShell 的 `ssh unitree@192.168.123.164` 核对指纹并登录。遇到主机密钥变化，不会自动信任或覆盖旧记录。

## 使用

1. 依赖就绪后，双击 `启动_G1语音控制.cmd`。
2. 输入用户名和 SSH 密码，点击“连接”。连接成功后自动读取机器人当前音量。
3. 在大文本框内编辑中文、英文或混合内容，并选择“播报语言”：自动选择、中文、English 或中英混合。
4. 用滑块或数字框选择目标音量（整数 0–100）。目标初始值为 30，与机器人当前音量分开显示；拖动滑块不会立即发送设置。
5. 点击“按此音量播报”，先设置目标音量，再按所选语言发送播报请求。
6. 也可点击“仅设置音量”或“读取当前音量”。音量 0 为静音。
7. 完成后点击“断开”或关闭窗口。

## AI 语音助手

1. 填写 DeepSeek API Key，也可预先设置环境变量 `DEEPSEEK_API_KEY`。
2. 等待窗口显示“SenseVoiceSmall INT8 已就绪”。模型只在启动后加载一次，后续对话复用内存实例。
3. 选择输入源，把鼠标按在“按住说话”按钮上立即开始录音；说完后松开鼠标，程序随即停止录音并发送识别文字。
4. 流程固定为：麦克风录音 → 本地 SenseVoiceSmall 识别 → 文字发送给 DeepSeek → G1 内置 TTS 播放。

正常结束条件是松开按钮，不再使用固定录音秒数。程序仍保留 120 秒安全上限，以防窗口或浏览器没有收到鼠标松开事件。按钮附近持续显示数据去向，因此按下按钮本身即表示开始本轮录音。

软件内不再包含 OpenAI 地址、模型、密钥或接口。录音不会上传；DeepSeek 只接收识别文字、系统提示和最近三轮对话。DeepSeek 使用官方 `deepseek-flash`、关闭思考模式并接收流式结果。

## 本地语音识别

- 引擎：`sherpa-onnx` CPU 版。
- 模型：SenseVoiceSmall INT8，支持中文和英文自动识别、中英混说、标点及数字规范化。
- 模型文件：`asr_models\sensevoice-small-int8\model.int8.onnx` 与 `tokens.txt`。
- 依赖安装在本目录的 `gui_deps`，不会修改系统 Python。
- 启动后模型在后台预加载；加载失败时文字播报、音量和外部 WAV 功能仍可使用，但对话按钮保持禁用。

## 语音助手输入源

- **G1 内置麦克风**：按下按钮时加入宇树官方音频组播 `239.168.123.161:5555` 并立即保留 PCM，松开按钮后退出组播。格式为 16 kHz、单声道、16-bit PCM。
- **电脑麦克风**：使用 Windows 默认输入设备；同样按下开始、松开停止。
- G1 麦克风要求电脑的有线网卡处于 `192.168.123.x` 网段，并允许 UDP 5555。若收到的数据全为零，请在 G1 App 中启用语音助手的唤醒/对话模式。
- 若组播被固件或 Windows 防火墙阻止，窗口会显示具体错误；可临时切换到电脑麦克风，不会自动改用其他输入源。

## 延迟优化

- G1 麦克风在鼠标松开后立即结束，不再等待静音判定或固定录音上限。
- SenseVoiceSmall 使用 INT8 CPU 推理并在启动后常驻内存。
- DeepSeek 使用非思考的 Flash 模型并限制语音回答长度。
- 回复直接使用 G1 内置 TTS，省去云端语音合成和整段 WAV 上传时间。
- 日志分别显示录音、本地识别、模型回复、声音提交和整轮耗时，便于判断瓶颈。
- 为避免重复收费、重复播报或状态不确定，网络失败后不会自动重试。

## 外部音频播放

1. 在“外部音频播放”区域点击“选择 WAV 文件”。可使用电脑上的外部 TTS、录音或已制作的提示音。
2. 程序只接受 **16 kHz、单声道、16-bit PCM WAV**，最长 5 分钟；不符合格式的文件不会发送给机器人。
3. 选择成功后，连接机器人，设置目标音量，点击“按此音量播放文件”。音量会先设置，再发送音频。
4. 音频通过当前 SSH 连接流式传输，播放时不会保存到 G1 磁盘。MP3、AAC、立体声和其他采样率需要先在外部工具中转换为上述 WAV 格式。
5. 外部音频的播放完成仍以现场听感为准。断线或超时后不要立即重试，先确认机器人是否已经开始播放。

## 播报语言

- **English**：使用宇树英文模式（speaker_id=1），例如 `Hello, welcome to our laboratory.`。
- **中文**：使用宇树中文示例模式（speaker_id=0）。
- **中英混合**：按出现顺序将中文和含英文字母的片段分别提交：中文用 speaker_id=0，英文用 speaker_id=1。空格和标点附在前一个语言片段上。
- **自动选择**（默认）：纯英文使用 English；纯中文使用中文；同一句同时包含汉字和英文字母时自动采用中英混合。仅数字或标点默认中文。
- 连续片段之间会根据文本长度等待约 1–10 秒，让前一段开始播放后再提交下一段。语音服务没有“播放完成”回调，因此这个间隔是估算值；可在现场根据效果调整。
- 例如 `你好 Unitree G1，Welcome to our laboratory.` 会依次提交中文“你好 ”、英文“Unitree G1，Welcome to our laboratory.”。如需更自然的停顿，建议使用句号、逗号或换行分隔短句。
- 本次混合拆分与顺序接口调用通过了本地模拟验证，尚未进行实际英文或混合播报验证。
- 本项更新适用于图形界面；原有命令行脚本仍沿用原先的中文模式。

## 行为说明

- 打开窗口不会自动连接机器人；点击连接会发起 SSH 连接并读取音量。
- 密码在窗口中隐藏显示，开始连接时清空输入框，不写入文件或日志。
- 每个操作在后台线程中执行；操作期间禁用命令按钮，避免重复提交。
- 按住说话期间，录音按钮保持可接收松开事件；松开后才进入识别、DeepSeek 和 TTS 阶段。
- 窗口日志仅保留在内存中。请求成功表示语音服务接受请求，不是播放完成通知。
- 调整音量后会保留设置，不自动恢复。如果后续播报失败，之前成功设置的音量也不会回滚。
- 断开或关闭窗口不等于停止已经提交的播报。超时或断线不会自动重试，请先确认现场情况。
- 功能仅涉及语音和音量，没有运动控制接口。
- API Key 仅保留在当前进程内存中，不写入配置文件或日志。
- G1 麦克风录音和云端生成的语音只在内存中处理，不保存到电脑或机器人磁盘。
- GUI 直接通过有线网络访问机器人，不需要用于下载安装的 FlClash / SSH 代理转发。
- 此阶段只进行了本地验证；图形界面的实际连机、调音量及播报测试需另行审批。

原有 `g1_remote_voice.py` 命令行脚本继续保留。

Jetson Docker 部署请参阅 `JETSON_DOCKER部署说明.md`。容器提供浏览器版按住说话界面，不依赖 Windows Tkinter。
